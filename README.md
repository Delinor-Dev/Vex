## О проекте
### Минимальные системные требования
**OC:** Linux
**Место на диске:** 100 Мб
**ОЗУ:** 32 Мб
**Архитектура:** x86-64


### Стек технологий
Проект был создан на языке программирования C++ с использованием библиотеки miniz. Используется стандарт C++17.  
Также из встроенной библиотеки STL были использованы: *vector, string, fstream, iostream, filesystem*.
