# Vex

*Vex - удобный проект для контроля версий, компиляции и сборки*

2. **[Установка и запуск](#установка-и-запуск)**
## О проекте
### Минимальные системные требования
**OC:** Linux  
**Место на диске:** 100 Мб  
**ОЗУ:** 32 Мб  
**Архитектура:** x86-64  


### Стек технологий
Проект был создан на языке программирования C++ с использованием библиотеки miniz. Используется стандарт C++17.  
Также из встроенной библиотеки STL были использованы: *vector, string, fstream, iostream, filesystem*.  

## Установка и запуск
### Инструкция установки и запуска проекта
#### Установка
1. Перейдите во вкладку *[Releases](https://github.com/Delinor-Dev/Vex/releases)*
2. Скачайте со страницы последнюю версию *Vex*(Установите файл в зависимости от вашей ОС)
#### Запуск
1. Создайте в папке с **вашим** проектом файл *info.vex*  
2. Заполните *info.vex*(Об этом читайте в главе **info.vex**
3. Откройте терминал и перейдите в папку с проектом: 'cd Путь/К/Папке'
4. Запустите утилиту: 'Путь/к/утилите/Vex'
