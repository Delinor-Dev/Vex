## О проекте
### О проекте
Даный проект позволяет сохранять, загружать и изменять версии проектов. Он работает на базе интерпритируемого языка сценариев **Vex**.  
Также он может удобно компилировать собранные проекты. 
### Минимальные системные требования
**OC:** Linux  
**Место на диске:** 100 Мб  
**ОЗУ:** 32 Мб  
**Архитектура:** x86-64  


### Стек технологий
Проект был создан на языке программирования C++ с использованием библиотеки miniz. Используется стандарт C++17.  
Также из встроенной библиотеки STL были использованы: *vector, string, fstream, iostream, filesystem*.  

## Установка и запуск
### Инструкция установки и запуска проекта
#### Установка
1. Перейдите во вкладку *[Releases](https://github.com/Delinor-Dev/Vex/releases)*
2. Скачайте со страницы последнюю версию *Vex*(Установите файл в зависимости от вашей ОС)
#### Запуск
1. Создайте в папке с **вашим** проектом файл *info.vex*  
2. Заполните *info.vex*(Об этом читайте в главе **[info.vex](#info.vex)**
3. Откройте терминал и перейдите в папку с проектом: `cd Путь/К/Папке`
4. Запустите утилиту: `Путь/к/утилите/Vex`

## info.vex
##### О языке
**Vex** - интепритируемый язык сценариев состоящий из нескольких команд, позволяющих создать инструкцию по сборке проекта.
##### Синтаксис
**Основные команды языка и их агрументы:**  
```vex
project("Путь к папке, где будут храниться версии", "Путь к папке проекта с которым работаем") // Инициализация рабочей среды  
ignore("Имя_файла.x") // Игнорировать файл при сборке
save("project", "v1.1.0") // Сохранить проект и его версию из рабочей директории
list() // Вывести список проектов
open("pr", "v1.1.0") // Выгрузить в рабочую директорию проект
load("pr", "v1.1.0", "a.cpp") // Выгрузить в рабочую директорию конкретный файл
delete("pr", "v1.1.5") // Удалить проект
// Также можно инициализировать без запятых и пробелов:
save("project" "v1.1.0")
save("project""v1.1.0")
```
Эти команды позволяют работать с проектами.  
В будующем планируется добавить команды компиляции и многое другое.
